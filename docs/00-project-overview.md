# 00 — نظرة عامة على المشروع

## ما هو CoverCast

لكل موقع حرج في إكسبو 2030 الرياض (نقطة إسعاف، بوابة، مدخل وفود)، ولكل مناوبة، يحسب CoverCast ما **يجب** أن يكون موجودًا (العدد والمهارات)، ويقارنه بما هو موجود **فعلًا** في الجدول. عند وجود فجوة يرتّب البدلاء المؤهلين، ويكتب سبب كل ترشيح وكل استبعاد. والمشرف وحده يعتمد.

**المبادئ الخمسة** (التقرير §3، مثبتة في `coverage/policy.py` وفي الاختبارات):

| المصدر | يحدد |
|---|---|
| الفعاليات | **أي** مهارة نحتاج |
| التنبؤ (اختياري) | **كم** شخصًا إضافيًا |
| الجدول | **من** موجود فعلًا |
| المحرك | الفجوة والمؤهلون |
| المشرف | القرار النهائي |

## مصطلحات

| المصطلح | المعنى هنا |
|---|---|
| خانة (slot) | مكان مفتوح واحد في موقع ومناوبة، وقد يشترط مهارات |
| فجوة مؤكدة (confirmed) | نقص في الأساس: غياب أو تكليف ناقص |
| فجوة متوقعة (anticipated) | نقص في الإضافات فقط: حدث أو حضور مرتفع |
| bundle | مهارات يجب أن تجتمع في **الشخص نفسه** |
| تكليف فعّال | حالته `planned` أو `confirmed` |
| أمان السحب (donor safety) | هل نقل الشخص من موقعه الحالي يضر ذلك الموقع؟ |
