# ADR 0006 — D6: مكان الكود

**الحالة:** معتمد (13 أكتوبر 2026)

- **السياق والمشكلة:** بيئة العمل السحابية مؤقتة وتُمسح، وGitHub غير مربوط بالجلسة.
- **الخيارات:** مستودع GitHub، أو تسليم مضغوط بعد كل مرحلة.
- **المختار:** مؤقتًا: Git محلي بتاريخ commits كامل، وملف zip يُسلّم بعد كل مرحلة، ونسخة من docs في مشروع Claude. ويُنقل إلى GitHub فور ربطه.
- **المبرر:** لا يضيع عمل، والتاريخ محفوظ داخل مجلد .git في الملف المضغوط.
- **العواقب والمقايضات:** المزامنة يدوية حتى الربط.
- **لماذا رُفضت البدائل:** —
