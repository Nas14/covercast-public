# ADR 0004 — D4: 18 نموذجًا بدل 16

**الحالة:** معتمد (13 أكتوبر 2026)

- **السياق والمشكلة:** تصميم التقرير لا يمثّل موقعًا بمهارتين أساسيتين، ولا إجازة بلا تكليف، ولا قواعد الفئة.
- **الخيارات:** إبقاء الـ16 مع حقول JSON، أو نماذج صريحة.
- **المختار:** حذف SecondmentScope (ManyToMany)، وإضافة SiteRequirement وAbsence وCategoryRule.
- **المبرر:** كل إضافة تحمل قاعدة أعمال حقيقية من البيانات، ولها قيود يمكن لقاعدة البيانات فرضها.
- **العواقب والمقايضات:** جداول أكثر بقليل، وكل منها موثق في 03-database-design.md.
- **لماذا رُفضت البدائل:** JSON يخفي القواعد عن قاعدة البيانات ويمنع القيود.
