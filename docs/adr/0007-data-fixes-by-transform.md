# ADR 0007 — إصلاح البيانات بسكربت تحويل لا بتعديل الملفات

**الحالة:** معتمد (13 أكتوبر 2026)

- **السياق والمشكلة:** الفريق أنهى دوره، والإصلاحات R1–R7 على عاتقنا.
- **الخيارات:** (أ) تعديل CSV يدويًا. (ب) تعديل مولّد رغد. (ج) سكربت تحويل من v0.1 إلى v0.2.
- **المختار:** (ج) data/build_v02.py: دالة لكل إصلاح، ويُتحقق منه بـ--check وباختبار.
- **المبرر:** v0.1 تبقى كما سلّمتها رغد، فالأصل محفوظ، وكل تغيير مقروء ومراجَع ومختبر.
- **العواقب والمقايضات:** ملفان للبيانات بدل واحد.
- **لماذا رُفضت البدائل:** (أ) لا أثر لما تغيّر ولماذا. (ب) تغيير المولّد قد يغيّر الأرقام العشوائية فيكسر الحالات المزروعة.
