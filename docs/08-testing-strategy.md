# 08 — استراتيجية الاختبار

## المبادئ

1. **لكل قاعدة اختباران:** واحد يثبت أنها تقبل الصحيح، وآخر يثبت أنها ترفض الحالة التي وُجدت من أجلها. قاعدة ترفض كل شيء تنجح في اختبار الرفض وحده.
2. **التخريب المتعمد (mutation check):** للقواعد الحرجة نحذف القاعدة مؤقتًا ونتأكد أن اختبارها **يفشل**. نُفّذ على:
   - قيد التكليف المزدوج (E-02)
   - إصلاح E-01
   - إهمال سجلات الغياب، والسماح ليوم وطني بإضافة عدد (المرحلة 4)
   - إعادة خطأ E-06، وتعطيل BREAKS_MINIMUM، وتجاهل تواريخ الانتهاء (المرحلة 5)
   - إعادة A-15 إلى `False` (5 اختبارات فشلت)
   - المرحلة 9: «الأقرب» للجميع، وإلغاء صياغة العدد، و**مفتاح طلب جديد لكل ضغطة في JavaScript** (التقطه اختبار المتصفح). كلها التُقطت.
   - المرحلة 8ب، ست تجارب: خط من Google Fonts، إزالة `localize off` (الأشرطة تنكسر بالفاصلة العربية)، أي مستخدم يرى الصفحات، المثنى خطأ، قسم «يحتاج قرارك» يهمل المتوقعة، الدرجة بلا خانتين. **كلها التُقطت.**
   - المرحلة 8أ، ست تجارب: أي مستخدم يُعدّ مشرفًا، إعفاء الاعتماد من CSRF، إعادة تسمية حقل في العقد، العربية كرموز `\u`، ترتيب الملخص بالعدد، صفحة العرض تقبل أي قيمة. **كلها التُقطت**، والأخيرة بعد إضافة اختبار كان ناقصًا (E-10).
   - المرحلة 6، سبع تجارب: بلا `BEGIN IMMEDIATE`، بلا إعادة فحص، بلا فحص مفتاح الطلب، بلا إلغاء التكليف السابق، بلا إرجاع المنقول، بلا فحص انتهاء المناوبة، بلا فحص الرد المكرر. **كلها التُقطت.**
3. **اختبار انحدار لكل خطأ** في `11-errors-and-fixes.md`.
4. **التوقعات لا يكتبها المحرك:** نتائج G1 مشتقة يدويًا ومحفوظة في commit مستقل **قبل** كود المحرك (`5a50a92`). وكشفت خطأً حقيقيًا (E-06) قبل كتابة أي اختبار.
5. **أداة واحدة:** مشغّل اختبارات Django المدمج، بلا تبعيات إضافية.
   - ملاحظة: اسم التطبيق `coverage` يتعارض مع مكتبة coverage.py، فلا نستخدمها. القرار مسجل هنا.

## التشغيل

```bash
python manage.py test                       # كل الاختبارات
python manage.py test coverage.tests.test_importer
python manage.py check
python manage.py makemigrations --check --dry-run
python data/build_v02.py --check
```
