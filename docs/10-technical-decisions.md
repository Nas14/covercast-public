## قرارات أصغر

| القرار | البديل المرفوض | السبب |
|---|---|---|
| Django 5.2 LTS | 6.1 | دعم حتى 2028، و`transaction_mode` منذ 5.1، والمراجع التعليمية |
| بلا DRF | DRF | أربع نقاط JSON فقط؛ تبعية واحدة أسهل للفهم والتشغيل بلا إنترنت |
| SQLite بوضع IMMEDIATE | DEFERRED + `select_for_update` | `select_for_update` لا يعمل على SQLite |
| `Zone` و`Skill` في `workforce` | في `coverage` | اتجاه اعتماد واحد (اختبار يفرضه) |
| `scope_zones` ManyToMany | نموذج `SecondmentScope` | لا بيانات على العلاقة نفسها |
| الأوزان في `policy.py` | جدول `RuleConfig` | تمر بالمراجعة والاختبار، ولا تتغير من لوحة الإدارة قبل العرض |
| PROTECT على الموظف والموقع والمناوبة | CASCADE | الحذف المتسلسل يمحو سجل التدقيق بصمت |
| مشغّل اختبارات Django | pytest-django، coverage.py | تبعية أقل؛ واسم التطبيق `coverage` يتعارض مع coverage.py |
| الفجوة تُحسب ولا تُخزن | جدول `Gap` (عند رغد) | حقيقة واحدة لا اثنتان |
