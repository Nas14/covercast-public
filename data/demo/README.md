## معنى أسطر `site_requirement`

- **سطر بلا `event_id`:** متطلب أساسي دائم.
- **سطر حدث بلا `bundle`:** الحد الأدنى **الكلي** للمهارة أثناء الحدث (يؤخذ الأكبر بينه وبين الأساسي، ولا يُجمع). مثال: S04 أساسي ترخيص أمني 1، وزيارة VIP تجعله 2 لا 3. هذا معنى مولّد رغد (`requirements()`: `max`)، وحافظنا عليه.
- **أسطر حدث بنفس `bundle`:** `min_count` شخصًا يحمل **كل** مهارات الـbundle معًا.
